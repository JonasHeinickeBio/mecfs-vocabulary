# ME/CFS and Long COVID knowledge graph: vocabulary

Vocabulary of the AID-PAIS literature knowledge graph. Published at
<https://jonasheinickebio.github.io/mecfs-vocabulary/>.

- `index.html`: the document graph's terms (generated from the project's vocabulary module).
- `ontology/*.ttl`: the OWL modules (`https://w3id.org/mecfs/ontology/...`).
- `shapes/*.ttl`: the SHACL shapes the graph is validated against.

Terms live under `https://w3id.org/mecfs/kg/`. The w3id.org redirect is being registered
(perma-id/w3id.org#7071) and will point here.
